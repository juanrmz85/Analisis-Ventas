Análisis de Datos de Ventas | Bootcamp TripleTen (2026)

Descripción: 
Realicé exploración, limpieza y preparación de datos, creación de métricas de negocio, dashboards interactivos y resumen ejecutivo a una base de datos de ventas de una cadena comercial.

En el presente documento, se llevo a cabo el análisis de las ventas por departamento, del periodo 2010 a 2012 de las tiendas Walmart.
